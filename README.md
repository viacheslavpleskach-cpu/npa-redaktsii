# npa-redaktsii — архів текстів і редакцій НПА України

Автор: В'ячеслав Плескач.

Тексти нормативно-правових актів і всіх їхніх редакцій із бази «Законодавство України»
(zakon.rada.gov.ua), а також інструмент `npa.py`. Він показує текст статті в редакції,
чинній на певну дату, історію змін статті та різницю між редакціями.

## Джерело та ліцензія

Дані взято з офіційного вебпорталу Верховної Ради України «Законодавство України»
(https://zakon.rada.gov.ua) і порталу відкритих даних (https://data.rada.gov.ua).
© Верховна Рада України. Контент доступний за ліцензією
[Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).
Кожен файл редакції містить посилання на свою сторінку на сайті.

Архів не є офіційним виданням. Для цитування в офіційних документах звіряйте текст із сайтом
за посиланням у файлі.

## Як користуватися

```bash
git clone --depth 1 https://github.com/viacheslavpleskach-cpu/npa-redaktsii
cd npa-redaktsii
python3 skrypty/npa.py akty                                  # що є в архіві
python3 skrypty/npa.py redaktsii КК                          # редакції з датами й підставами
python3 skrypty/npa.py stattia КК 375 --na 15.06.2020        # стаття в редакції, чинній на дату
python3 skrypty/npa.py zminy ЦПК 189                         # коли змінювалася стаття
python3 skrypty/npa.py porivniaty КАС 193 --z 01.01.2019 --po 01.01.2024
python3 skrypty/npa.py poshuk КПК "розумні строки" --na 01.03.2023
```

КУпАП на сайті розміщено трьома документами (до 07.05.2017 — статті 1–212 і 213–330; з 10.06.2017 —
чинний 8073-10); `npa.py` обирає документ за датою і номером статті.

Акт можна задати номером на сайті (`2341-14`), скороченням (`КК`, `КПК`, `"Закон про ВРП"`)
або словом із назви. Скрипт сам попереджає, якщо:
- на вказану дату акта ще не було або він ще не набрав чинності (сайт у такому разі показує
  чинну редакцію — її не можна використовувати як редакцію на дату);
- акт втратив чинність;
- є редакції, дата набрання чинності яких залежить від події (наприклад, «з дня припинення
  воєнного стану»);
- дата пізніша за останню перевірку архіву.

## Будова

| Шлях | Що містить |
|---|---|
| `perelik_aktiv.csv` | перелік актів: номер на сайті, скорочення, назва, режим зберігання |
| `akty/<номер>/kartka.json` | картка: назва, стан, усі редакції (дата, підстава), події (рішення КСУ, тлумачення тощо) |
| `akty/<номер>/red/<РРРРММДД>.txt` | текст редакції; `3000xxxx` — редакції з умовною датою набрання чинності |
| `skrypty/npa.py` | інструмент для роботи з архівом |
| `skrypty/sync_api_v4_1.py` | синхронізація архіву через API data.rada.gov.ua: `probe`, `sync`, `verify`, `anomaly`, `status` |
| `skrypty/patch_npa_v4_1.py` | патч `npa.py` v4.1 (уже застосовано; `--check`, `--revert`) |
| `skrypty/zbir.js` | попередній спосіб: браузерне збирання сторінок сайту; для оновлення не використовується |
| `skrypty/import.py` | розкладання зібраного `zbir.js` в архів і перевірки |
| `skrypty/onovlennia.py` | попередній спосіб щотижневого оновлення (через `zbir.js`); замінено `sync_api_v4_1.py` |
| `skrypty/novi_akty.py` | акти, згадані в нових висновках, яких немає в архіві (пропозиції) |
| `dani/` | службові дані: `novi_akty.py` (переглянуті висновки, кількість згадок); `manual_only.json` (акти, недоступні через API) і `perevirka.json` (дати перевірки) — створює `sync_api_v4_1.py` |
| `tests/` | 103 офлайн-тести синхронізатора й патча (`python -m unittest discover -s tests -p "test_*.py"`), `tests/live/` — живі перевірки на копії архіву |
| `docs/sync_api_v4_1/` | звіти розробки й аудиту v4.1–v4.1.6, результати тестів, перелік актів без API |

Режими зберігання: `povna` — усі редакції; `chynna` — лише чинна (Податковий кодекс);
`odyn` — один текст (документи без редакцій, закони про внесення змін); `nemaie` — акта на
zakon.rada.gov.ua немає.

## Оновлення

Архів оновлюється через офіційний API порталу відкритих даних (data.rada.gov.ua, JSON/TXT,
`User-Agent: OpenData`, паузи між запитами, денний ліміт обсягу) — HTML-сторінки сайту не
завантажуються:

```bash
python3 skrypty/sync_api_v4_1.py sync --changed          # щотижня: акти, змінені за doc-update
python3 skrypty/sync_api_v4_1.py sync --nreg 2343-12     # один акт
python3 skrypty/sync_api_v4_1.py verify --json verify.json   # аудит текстів, нічого не змінює
python3 skrypty/sync_api_v4_1.py status --out stan.md    # стан актів: повнота каталогу, тексти
```

Якщо в один день набрало чинності кілька редакцій, окрема редакція зберігається під ідентифікатором порталу
(9–10 цифр, напр. `akty/2343-12/red/201301186.txt`); порядок у межах дня — за карткою сайту (поле
`poriadok_u_dni`), і `npa.py` на таку дату застосовує останню з них і попереджає про це. Записує її
`anomaly --record-separate`, а виправлення опису чи підстави редакції — `pravka` (без мережі).

Текст API не завжди точний: у частині редакцій втрачено верхні індекси («Стаття 151» замість «Стаття 15-1»).
Тому старий текст замінюється текстом API лише за збігу змісту, а новий текст порівнюється з попередньою
редакцією; сумнівні редакції мають позначку `api_text_issue`, і `npa.py` попереджає про неї.

Портал відповідає лише на запити з України. Картка показує, чи повний каталог редакцій
(`edition_catalog_complete`) і чи перевірено тексти; `npa.py` попереджає, якщо ні. Шість актів,
недоступних через API, перелічено в `dani/manual_only.json` (оновлюються вручну). Нові акти додає
власник репозиторію.
