## 1. Мета і принцип роботи

База НПА з редакціями зберігається в публічному репозиторії `viacheslavpleskach-cpu/npa-redaktsii`. Порядок звернення до норм — для скіла npa-redaktsii і для всіх скілів і промтів, що цитують норми (висновки, рішення, оцінка доводів скарг):

1. **Спершу база.** Акт і редакція беруться з архіву (`npa.py`).
2. **Якщо акта або потрібної редакції немає** — отримати текст із сайту Верховної Ради доступним і зручним способом:
   - основний спосіб — офіційний API data.rada.gov.ua (`sync_api_v4_1.py`), лише з мережі в Україні, тобто з ПК власника;
   - разово — сторінка сайту в браузері власника (Claude in Chrome);
   - автоматичне завантаження HTML-сторінок zakon.rada.gov.ua не використовується: robots.txt (`User-Agent: *` → `Disallow: /`) його забороняє.
3. **Отримане зберігається в базу** після підтвердження власника (див. п. 2.1).
4. **У звіті** для кожної норми зазначається джерело тексту (база або сайт), редакція і дата застосування.

Ліміти API: до 60 запитів на хвилину, бажана пауза 5–7 с, 200 МБ на добу на одну IP-адресу (локальний бюджет — 150 MiB).

## 2. Прийняті рішення

1. **Додавання в базу — лише з підтвердження власника**, і для нових актів, і для нових редакцій.
2. **Обсяг зберігання.** Великі кодекси й закони — з повною історією (підтверджено 24.11.2026). Для нових актів за замовчуванням — чинна редакція, інші — на вимогу.
3. **Один репозиторій.** Розбиття повертаємося обговорювати, коли стиснутий обсяг наблизиться до 1–2 ГБ.
4. **Частковий клон** у кожному чаті: скрипти, перелік і картки плюс теки потрібних актів.
5. **Єдине правило для інших скілів:** база → отримання з сайту → позначка джерела у звіті.
6. **Шість актів поза API** — оновлюються вручну: Claude звіряє картку сайту в браузері власника; результат — `perevireno` і `ruchna_perevirka` у картці. Лист порталу не надсилати.
7. **Оновлення бази** — одним commit-ом з підсумком за запуск.
8. **Кілька редакцій в один день** — ідентифікатор порталу (9–10 цифр) як є; порядок у дні — за карткою сайту; помилкові підписи — `pravka`.
9. **ПК для оновлень** — комп'ютер власника з обліковим записом `user`; робоча копія — `C:\Users\user\Documents\npa_full\npa-arkhiv` (на хмарному диску не тримати). Старі тексти не видаляти разом, а замінювати поступово.
10. **Текст API не вважати еталоном (24.11.2026).** У частині редакцій TXT API втрачає верхні індекси («Стаття 151» замість «Стаття 15-1», «пунктом 2581» замість «258-1»), а КПК ed20140302 містить главу 41-1, якої в редакції на сайті немає (звірено в браузері). Тому: старий текст замінюється текстом API лише за збігу змісту й без втрати індексів; новий текст порівнюється з попередньою редакцією; сумнівні — `api_text_issue`, `npa.py` попереджає.
