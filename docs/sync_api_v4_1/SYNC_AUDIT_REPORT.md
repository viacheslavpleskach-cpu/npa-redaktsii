## 2. Поле modified у doc-update (живий файл, 17,7 МБ, Last-Modified 21.11.2026 01:57:38 GMT)

- Файл має рядок заголовка `modified<TAB>nreg<TAB>ed`; 454 610 рядків, 295 899 документів.
- `modified` — ISO-час окремо для **кожного рядка (редакції)**, не для документа: у документа з кількома
  рядками зазвичай кілька різних значень (2343-12: 75 рядків, 17 різних modified; КАС: 149 рядків, 5 значень;
  ЦПК: 121 рядок, 5 значень). Дата modified збігається з датою ed лише у 22 320 рядках (≈5 %), тобто це час
  оновлення запису в базі, а не дата редакції.
- Тому v4.1 бере для акта **максимум** modified його рядків (КАС — 2026-10-27T00:40:10, ЦПК — 2026-08-07T15:55:06,
  2343-12 — 2019-10-21T01:45:07). Нерозпізнаних значень — 0.
- Чи змінюється modified, коли змінюється лише картка (подія, статус) без нового ed, — з одного знімка файла
  встановити неможливо; логіку перевірено офлайн-тестом. Підтвердиться наступними щотижневими запусками.

## 3. Некоректні ідентифікатори редакцій

- У doc-update 260 рядків із ed не з 8 цифр: 227 — 9 цифр, 33 — 10 цифр (напр. 1952-15: `201601010`,
  v0018500-22: `202202244`, 994_049: `1985062322`). Схоже на «дата + номер редакції того самого дня».
- **2343-12 / 201301186.** Рядок має той самий modified (2014-06-04T17:15:05), що й рядок `20130118`.
  API на `ed201301186.txt` повертає HTTP 200 і DocumentDate 18.01.2013, але **текст відрізняється** від
  `ed20130118.txt` (325 751 символ; SHA-256 різні). Отже, це, імовірно, **друга редакція від 18.01.2013**, а не
  дубль. В архіві є лише один текст за 18.01.2013, тож одна редакція того дня може бути відсутня; повноту
  історії 2343-12 правильно не підтверджено, `npa.py` попереджає. Закон втратив чинність 21.10.2019 —
  практичний ризик лише для подій 2013 року.
- Що далі (рішення власника): (а) звірити на картці акта на сайті вручну, чи є дві редакції від 18.01.2013 і яка
  з них остання; (б) якщо так — зберігати другу редакцію окремим файлом (потрібен формат ідентифікатора,
  який npa.py розуміє, напр. `20130118_6`; зміна npa.py — окремим патчем).
