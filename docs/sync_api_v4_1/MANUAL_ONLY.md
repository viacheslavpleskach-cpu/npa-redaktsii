## Правила

* Наявні тексти цих актів не змінюються і не видаляються.
* Відсутність рядка в doc-update сама не робить акт «ручним»: статус ставиться лише після відповіді API
  (HTTP 302/404 або порожня картка) і перевіряється знову раз на 30 днів.
* HTML-сторінки zakon.rada.gov.ua автоматично не завантажуються (robots.txt: `User-Agent: *` → `Disallow: /`).

## Ручне оновлення (власник)

1. Раз на місяць (або коли акт потрібен у документі) відкрити картку акта на zakon.rada.gov.ua у браузері.
2. Звірити дату останньої редакції з `kartka.json`. Якщо з'явилася нова — відкрити сторінку редакції,
   перевірити рядок «Редакція від …» і зберегти текст.
3. Спосіб імпорту збереженого вручну тексту в архів — **відкрите питання**: колишній браузерний збирач
   `zbir.js` автоматизує завантаження сторінок, тому для цього workflow не рекомендується. Пропозиція —
   окремий маленький `import_manual.py` (текст + дата + підстава → `red/<ed>.txt` і рядок картки з позначкою
   `source: manual`), після погодження.

роботі, ми отримуємо картки й тексти документів через офіційний API data.rada.gov.ua (`/laws/card/<nreg>.json`,

встановлених обмежень частоти запитів.
