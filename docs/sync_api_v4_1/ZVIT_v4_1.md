## 1. Що змінено і чому
Див. `CHANGELOG.md` і `v4_to_v4_1_5.diff` (кумулятивний diff від v4). Коротко: консервативна повнота історії з окремим обліком некоректних
ідентифікаторів (без подвійного підрахунку); per-document `modified` для `--changed`; явний `status=0`;
аудит цілісності текстів `verify`; контроль актуальності `podia.txt`; реєстр актів поза API з доказом;
`dani/perevirka.json`; журнал HTTP і облік трафіку; ідемпотентні записи; патч `npa.py` окремо.
Понад ТЗ виправлено: декодування UTF-8 як cp1251 (mojibake), дублі подій при зміні назв у podia.txt,
втрату SHA-256/DocumentDate між запусками, застарілу дату перевірки для незмінених актів у `--changed`,
хибну «зміну статті» через різні апострофи (важливо для позначення архівних редакцій), CRLF на Windows.

  (`verify --repair --include-legacy --nreg …`) для редакцій, які цитуються.
- 2343-12: друга редакція від 18.01.2013 (`201301186`) не збережена; повнота не підтверджена (SYNC_AUDIT_REPORT, розд. 3).

- Реакцію `modified` на зміну картки без нового ed наживо не спостерігали (лише офлайн-тест).
